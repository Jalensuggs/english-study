# 英语学习网站 UI 重做 · spec 与方向卡

## spec（三个方向共用，只写要说什么）

- **项目**：自用的雅思阅读 + 短语学习工具。本地 Python 服务 + 原生 JS，电脑为主、手机也用。
- **受众与场景**：一个人，每天学 30–90 分钟。最常用的三个屏：①题库（挑一篇）②做题页（左文章右题目，用学习笔/记号笔/橡皮擦，计时，提交判分）③短语单元（70 个单元列表 → 单元页 → 上/下一单元）。
- **情感基调**：清爽现代（用户原话「清爽现代」，参考 Notion / Linear / Apple 自带 App 的方向）；浅色深色都要，跟系统切换。
- **必须解决的痛点**（用户原话归纳）：
  1. 做题页进入后顶部导航栏要消失，专注做题
  2. 返回箭头要显眼，不然用起来不丝滑
  3. 短语单元的「上一单元/下一单元」太小
  4. 回到「全部单元」时要显示上次点的单元，不然很难找
  5. 现在的墨绿 + 米色太丑，整套换掉
- **输出格式**：网页原型，1440×900 桌面首屏 + 375×812 手机，单文件 HTML，三版同内容（剑18 Test 1 Passage 1 *Urban farming* 真实文本和题目、第 7/8/9 单元短语）。
- **素材**：T0（无生图）。主角素材就是真实内容本身：文章正文、题目、记号笔的高亮、做题进度。

## 六个候选

### ① 最佳设计师 · iA（Information Architects，Oliver Reichenstein）
- **借的**：「排版就是界面」——只有一栏 64 字符宽的正文；界面元素降到最少，用字重和灰度分层而不是框和卡片；专注模式让当前段落之外的文字变灰
- **主角素材**：文章正文本身 + 黄色荧光笔高亮
- **骨架**：做题页左文右题，无卡片无边框，只有一条发丝分隔线；顶部一条极简工具条，返回是带「题库」字样的大按钮
- **胆量**：专注模式——点哪段，哪段变黑，其他段落退成浅灰
- **form 来自**：阅读题考的就是阅读，界面让位给文字

### ② 最佳设计师 · Linear 设计团队（Karri Saarinen）
- **借的**：左侧细线图标导航 + 文档式内容区、编号用等宽字、1px 细线分隔、⌘K 命令面板、深色优先但浅色同样精致
- **主角素材**：题号做成等宽小标签（Q14），每套题的完成进度
- **骨架**：左侧栏是「书 → Test → Passage」树，右边是内容；做题页侧栏收起，变全屏双栏
- **胆量**：键盘优先——每页都显示快捷键提示（Esc 返回、J/K 上下单元）
- **form 来自**：一套题 40 道 = 40 个待解决的条目

### ③ 现实参照 · Brilliant.org（亲眼截图）
- **借的**：浅暖灰底 + 大白圆角卡片、衬线大标题、紫色和薄荷绿只做小面积点缀、胶囊按钮、学习路径
- **主角素材**：圆形进度环、单元做成一条路径
- **骨架**：居中卡片流；短语 70 单元排成带进度的路径网格，上次学的单元放大高亮
- **胆量**：短语单元路径——上次学到哪一眼看见
- **form 来自**：学习是一步一步走的

### ④ 现实参照 · Readwise Reader（只看到营销页，**未亲眼看到 App 阅读界面**）
- **借的**：近黑底 + 柔和珊瑚色胶囊按钮、Inter 类无衬线、高亮作为一等公民
- **主角素材**：多色荧光高亮
- **骨架**：深色阅读器，右侧高亮笔记栏
- **胆量**：高亮自动汇总成侧栏笔记
- **form 来自**：记号笔是这个工具的核心动作

### ⑤ 秒数轮盘 38 → 网页 19 号 · Swiss 极致黑白
- **借的**：纯黑白 + 灰阶、Geist、直角无圆角、发丝边框、精密网格、巨大标题
- **主角素材**：巨号字（Passage 标题、分数）
- **骨架**：题库是一张严格网格表；做题页黑白双栏
- **胆量**：提交后分数用巨号字铺满结果区
- **form 来自**：考卷就是黑字白纸

### ⑥ 秒数轮盘 38 → 东亚 3 号 · 民国书衣
- **借的**：土黄纸色、墨黑 + 一点朱红、双线边框、竖排题签条
- **主角素材**：书封式的书籍卡片（剑18 做成一本书的封面）
- **骨架**：题库是书架上的书封平铺
- **胆量**：竖排题签
- **form 来自**：题库本来就是几本书
- **预判**：英语内容配民国书封，去掉这个手法信息反而更清楚 → 大概率「用力过头」，只做缩略图
